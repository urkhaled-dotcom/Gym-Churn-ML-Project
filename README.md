# نظام تحليل مخاطر انسحاب المشتركين من النادي الرياضي

**Gym Member Churn Prediction & Retention Analysis** — مشروع تطبيقي لتعلم الآلة مع دفتر عربي، ومقارنة نماذج، وتفسير النتائج، وتطبيق تجريبي تفاعلي.

## ملخص المشروع

يحلل المشروع مجموعة بيانات منشورة تتضمن 4,000 سجلًا و13 خاصية للمشتركين وعمود الهدف `Churn`، حيث `1` يعني الانسحاب وفق ترميز المصدر و`0` يعني عدم الانسحاب. نقارن عدة نماذج تصنيف، ونختبر هل تضيف هندسة الخصائص قيمة، ثم نقيّم أفضل إعداد على مجموعة اختبار منفصلة لم تدخل في اختيار النموذج أو عتبة القرار.

> **تنبيه منهجي مهم:** وصف المجموعة المتداول يذكر أن خصائص المشترك تخص الفترة السابقة لقرار/حالة الانسحاب. لكن الملف نفسه لا يتضمن معرفًا زمنيًا مستقلًا أو سجلات متكررة لكل مشترك. لذلك فإن التقييم هنا يقيس التنبؤ بملصق `Churn` في هذه المجموعة وفق تقسيم طبقي، ولا يثبت وحده قابلية التعميم الزمني أو صلاحية الاستخدام في نادٍ حقيقي. قبل التطبيق الفعلي يجب التحقق من توقيت كل خاصية وجمع بيانات لاحقة زمنية من النادي.

## محتويات المشروع

- `data/gym_churn_us.csv` — البيانات التي رفعها المستخدم.
- `notebooks/Gym_Churn_Arabic.ipynb` — دفتر تحليلي منظم باللغة العربية، مع رسومات ونتائج فعلية.
- `src/features.py` — هندسة الخصائص المشتقة.
- `src/train.py` — خط التجارب: تدقيق البيانات، تقسيم طبقي، مقارنة نماذج وخصائص، ضبط محدود لأفضل نموذج، اختيار العتبة باستخدام تنبؤات خارج الطية من التدريب، تقييم الاختبار، حفظ النتائج والرسومات.
- `src/predict.py` — واجهة سطر أوامر لتوقع الانسحاب من ملف CSV جديد.
- `app.py` — لوحة تجريبية تفاعلية باستخدام Streamlit.
- `models/gym_churn_model.joblib` — خط المعالجة والنموذج النهائي المختار.
- `reports/` — مقاييس التقييم، مقارنة النماذج، التنبؤات، أهمية الخصائص، الرسومات، وتقرير النتائج.
- `tests/` — اختبارات أساسية لسلامة البيانات وهندسة الخصائص والتنبؤ.

## النتائج النهائية المسجلة

تم اختيار `HistGradientBoosting` مع الخصائص المهندسة استنادًا إلى متوسط `PR-AUC` في التحقق المتقاطع على التدريب.

- `PR-AUC` في متوسط التحقق المتقاطع: **97.32%**.
- `PR-AUC` على الاختبار النهائي: **97.96%**.
- `ROC-AUC` على الاختبار النهائي: **99.04%**.
- عند عتبة القرار المختارة من تنبؤات التدريب خارج الطية (`0.22` بهدف إعطاء وزن أكبر للاستدعاء): الاستدعاء **93.87%** و`F1` **91.49%** و`F2` **92.90%**.

هذه نتائج داخلية عالية على مجموعة البيانات المتاحة، وليست ضمانًا لنتيجة مماثلة على بيانات نادي آخر. راجع `reports/FINAL_RESULTS_AR.md` لمعرفة المقاييس وحدود تفسيرها، ولا تعتبر الاحتمالات تنبؤات مؤكدة أو احتمالات معايرة ما لم يُختبر ذلك.

## طريقة التشغيل محليًا

ينصح باستخدام Python 3.10 أو أحدث.

```bash
# من داخل مجلد Gym_Churn_ML_Project
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python -m src.train --data data/gym_churn_us.csv --out .
```

إذا أردت إعادة التجارب كاملة بدل تحميل النتائج المحفوظة، استخدم:

```bash
python -m src.train --data data/gym_churn_us.csv --out . --force
```

قد يستغرق التدريب وإعادة المقارنة عدة دقائق اعتمادًا على الجهاز. يتم تثبيت `random_state` كي يسهل تكرار النتائج، مع العلم أن اختلاف إصدارات المكتبات قد يُحدث اختلافات طفيفة.

### فتح الدفتر

افتح `notebooks/Gym_Churn_Arabic.ipynb` من Jupyter Notebook أو VS Code مع جعل مجلد المشروع هو مجلد العمل، ثم نفّذ الخلايا بالترتيب. الدفتر يستخدم النتائج المحفوظة افتراضيًا كي يفتح بسرعة؛ لتكرار تدريب النماذج، غيّر `RETRAIN_FROM_SCRATCH` إلى `True` في خلية التدريب.

### تشغيل لوحة العرض التفاعلية

```bash
streamlit run app.py
```

توفر اللوحة ملخصًا للنتائج، ومقارنة النماذج، وأهمية الخصائص، ونموذجًا تجريبيًا لإدخال خصائص مشترك وعرض نتيجة النموذج. لا تتصل اللوحة بنظام نادٍ حقيقي، ولا ينبغي اتخاذ قرار ضد مشترك بناءً على هذه البيانات التجريبية وحدها.

### استخدام النموذج من ملف CSV

أنشئ ملفًا يحتوي على الخصائص الـ13 الأصلية وبنفس أسماء الأعمدة، دون الحاجة إلى عمود `Churn`. يمكن استخدام `reports/sample_input_for_prediction.csv` كقالب.

```bash
python -m src.predict --model models/gym_churn_model.joblib --input reports/sample_input_for_prediction.csv --output reports/predictions_new_data.csv
```

## المنهجية باختصار

1. تدقيق الصفوف والأنواع والقيم المفقودة والتكرارات والقواعد المنطقية.
2. تقسيم طبقي 80% تدريب و20% اختبار مع `random_state=42`.
3. مقارنة نماذج مختلفة عبر 3 طيات طبقية على التدريب فقط، مع `PR-AUC` و`ROC-AUC` ومقاييس تصنيف أخرى.
4. مقارنة الخصائص الأصلية بالخصائص المهندسة من نفس المدخلات.
5. اختيار أفضل إعداد وفق متوسط `PR-AUC` في التحقق المتقاطع، ثم ضبط محدود للمعاملات على التدريب.
6. اختيار عتبة القرار من تنبؤات خارج الطية المتداخلة للتدريب فقط، مع تعظيم `F2` لأن اكتشاف المشتركين المحتمل انسحابهم مهم، مع توضيح كلفة الإنذارات الكاذبة.
7. تقييم نهائي واحد على مجموعة الاختبار بعد تثبيت اختيارات النموذج والعتبة.

## مصادر وحدود البيانات

مصدر صفحة مجموعة البيانات: [Kaggle — Gym Customers Features and Churn](https://www.kaggle.com/datasets/adrianvinueza/gym-customers-features-and-churn).
