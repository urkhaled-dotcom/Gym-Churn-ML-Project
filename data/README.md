# البيانات

`gym_churn_us.csv` هي نسخة ملف البيانات التي رفعها المستخدم للمحادثة، وقد حفظت داخل الحزمة لأجل إعادة تشغيل التحليل.

المصدر الذي حدده المشروع: https://www.kaggle.com/datasets/adrianvinueza/gym-customers-features-and-churn

قبل إعادة توزيع البيانات أو نشر الحزمة للعامة، راجع ترخيص مجموعة Kaggle وشروط النسبة للمصدر. الملف يحتوي على أعمدة خصائص مشتركين وعمود الهدف `Churn`.
